# HeyTora for Windows

An AI companion for Windows: hold a key and ask - Tora hears you, looks at
your screen when it needs to, and points at what to click.

**[Download the latest installer](https://github.com/Qwickly/heytora/releases/latest/download/Setup-HeyTora.exe)** ·
[download page](https://qwickly.github.io/heytora/) · [all versions](https://github.com/Qwickly/heytora/releases)

This repository holds the installers and the download page only.

## Getting started

1. Run `Setup-HeyTora.exe` (Windows 10/11, 64-bit). It installs for you
   alone, no admin needed. This test build is not signed yet, so Windows
   may say it does not recognise it: **More info → Run anyway**.
2. Get a free Google Gemini API key at
   <https://aistudio.google.com/app/apikey> and paste it when HeyTora asks.
3. Hold **Ctrl + Win** and talk.

HeyTora sends what you say - and, when it needs to look, a picture of your
screen - to Google's Gemini using your API key, and web searches to a
search engine. Uninstall any time from Settings → Apps.
